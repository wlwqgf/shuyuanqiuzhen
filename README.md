**2026 年北京市大学生金融人工智能竞赛 · 选题五（研究报告纠错核查）**

团队：数据一定队 —— 敖潇文（语义与编排层）/ 梅睿涵（规则引擎与计算视觉层）/ 马可（材料与合规）

## 这是什么

对券商研究报告中的财务数据进行自动化纠错核查的智能体系统。

核心设计：

- **双通道核查**：确定性规则引擎（勾稽关系 / 单位 / 口径重算）+ 大模型语义判定，
  两通道不一致的结论进入人工复核队列，不自动定罪
- **证据锚定**：每条结论必须携带四元组证据——源文件 / 页码 / 原文片段 / 计算过程
- **证据分级**：A 级（文字层直命中）可判定，B 级（OCR ≥ 0.9）可判定，
  C 级（图表反推或 OCR < 0.9）只报疑似、不定罪
- **评测隔离**：标注集与评测框架由不同成员独立实现，防止自证循环

## 快速开始

```bash
# 1. 建虚拟环境并安装依赖（Python 3.11+）
python -m venv .venv && .venv/Scripts/activate
pip install -r requirements.txt

# 2. 一键启动（Windows 双击 启动.bat 亦可）
streamlit run web/app.py
```

演示模式**无需任何 API 密钥**，打开即用。
