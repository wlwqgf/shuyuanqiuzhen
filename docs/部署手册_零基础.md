> 适用对象：没有任何部署经验的队员。全程网页操作，不用敲命令。
> 目标：把 `fincheck` 仓库变成在线可访问的智能体网站。

## 一、当前状态（2026-10-14）

- 代码已推到 GitHub：`github.com/wlwqgf/shuyuanqiuzhen`
- 网站入口文件：`web/app.py`（Streamlit 应用）
- 演示模式**不需要任何 API 密钥**，部署后立即可用
- 后端核心功能排期 10/18 后接入，接口已在 `web/api_client.py` 预留

## 二、部署到 Streamlit Cloud（约 5 分钟）

1. 打开 https://share.streamlit.io ，用 **GitHub 账号登录**（授权页面点同意）
2. 点右上角 **New app**（或 "Create app"）
3. 弹出页面里：
   - **Repository** 选 `wlwqgf/shuyuanqiuzhen`
   - **Branch** 保持 `main`
   - **Main file path** 填 `web/app.py` ← **最容易填错的一项，别漏了 `web/`**
4. 点 **Deploy**，等 1–2 分钟，出现网址即成功（形如 `https://xxx.streamlit.app`）
5. 把网址发给队长，视频录屏、计划书里都能用

## 三、以后更新网站（重要机制）

改代码 → 提交并推送 → **Streamlit Cloud 自动重新部署**。

- ⚠️ 必须是**真实文件改动**才会触发自动部署；空提交（empty commit）不会触发
- 如果推送后网站没变化，去 Streamlit 后台点 **Reboot** / **Redeploy** 最可靠
- 每次部署约 1 分钟，期间旧版本仍可访问

## 四、常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| 部署报 "ModuleNotFoundError" | 依赖没装全 | 确认 `requirements.txt` 在仓库根目录且包含 `streamlit` |
| 打开是 "Manage app" 空白页 | 应用在休眠 | 点一下 **Wake up**，等 30 秒刷新 |
| 页面报错提到 secrets | 代码读了不存在的密钥 | 演示模式不需要密钥；如报错检查是否误开了 api 模式 |
| Main file path 填错 | 填成 `app.py` | 改回 `web/app.py`，保存后自动重部署 |

## 五、10/18 后接入后端时

1. 实现 `web/api_client.py` 里的 4 个接口（`submit_check` / `poll_task` / `get_findings` / `get_docs`）
2. 把 `DATA_SOURCE` 从 `"demo"` 改为 `"api"`
3. 若需要模型密钥：Streamlit 后台 → 应用 → **Settings → Secrets**，按 `.env` 的格式粘贴（密钥只进服务端，不进前端）
4. 推送真实文件改动，等自动部署完成

## 六、备用推送通道（github.com 被网络阻断时）

个别网络环境推不上 GitHub（git push 报连接错误）。此时：
- `api.github.com` 通常仍可达，用 `tools/push_via_api.py` 经 GitHub 官方 API 重建历史
- 用法见脚本内 docstring；token 用 `.ghtoken` 文件传入，**用完删除并去 GitHub 设置里撤销**
