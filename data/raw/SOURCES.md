# 原始材料来源登记表

> **用途**：本项目所有原始财务材料的来源凭证。竞赛要求"数据来源可核验"，因此每份材料均须在此登记来源链接与文件哈希。
>
> **为什么不把 PDF 直接提交进 Git**：① 年报与券商研报体积大（单份常达 3–10 MB）；② 券商研报受版权保护，公开仓库分发存在合规风险。因此采用"材料不入库、来源入库"的方式——评审方按本表链接自行下载，并用 SHA256 校验是否为同一份文件，可复现性不受影响。
>
> **登记纪律**：每新增一份材料，**立即**登记，不得事后补记。哈希由 `tools/hash_files.py` 批量生成。

---

## 一、字段说明

| 字段 | 含义 |
|---|---|
| 文件标识 | 程序内部使用的文档 ID（`doc_id`），生成规则见 `docs/data_spec.md` |
| 文件名 | 下载得到的原始文件名 |
| 材料类型 | 原始财务材料 / 待核查研报草稿 |
| 主体 | 材料对应的上市公司名称 |
| 报告期 | 材料所覆盖的会计期间 |
| 来源渠道 | 巨潮资讯网 / 交易所公告 / 券商官网 / 其他公开渠道 |
| 来源链接 | 可直接下载的公开链接 |
| 下载日期 | 下载当日日期 |
| SHA256 | 文件内容哈希，用于校验评审方拿到的是同一份文件 |
| 用途 | 该材料在核查流程中承担的角色 |
